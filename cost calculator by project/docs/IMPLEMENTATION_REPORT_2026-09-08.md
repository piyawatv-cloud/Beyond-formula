### 2.3 สิ่งที่ **จงใจไม่ทำ** — อย่าไปทำโดยไม่มีคำสั่งใหม่

- **ไม่แตะ `CostCalculator` core เรื่องตัวตน scenario** — core บังคับ `projectId` (`SCENARIO_IDENTITY_REQUIRED`)
  งานลอยจึงใช้รหัสใบงานต้นทุน `CJ-…` เป็นคีย์แทน ไม่ได้แก้กฎของ core
- **ไม่คิด VAT** — เจ้าของยืนยัน "ไม่รวม VAT" ระบบจึงติดป้ายอย่างเดียว ไม่บวกอัตรา
- **ไม่ตั้งนโยบายอายุราคา** — เจ้าของสั่งพักไว้ ใช้ธง `VALIDITY_FROM_POLICY` เป็นจุดพักที่ปลอดภัย
- **ไม่สลับ Tier ให้อัตโนมัติ** เมื่อเกินเพดาน MOQ และ**ไม่เลือกข้อเสนอให้เอง** แม้เจอตัวเดียว
- **ไม่ sync `fs_cost` ขึ้นเซิร์ฟเวอร์** — ADR 0002 ยังใช้ (local-first)
- **ไม่ deploy ไม่เปิด PR ไม่ push** — ตามข้อจำกัดของงานนี้
