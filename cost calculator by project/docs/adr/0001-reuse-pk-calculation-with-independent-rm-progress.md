# Reuse PU-PK calculations while formula and RM progress independently

ผู้ใช้ยืนยัน Q30 ให้ PU-PK เป็นเจ้าของการเลือก item/Tier และผลคำนวณ PK แบบมีเวอร์ชัน โดย calculator อ้างอิงผลที่ตรวจสอบแล้วมารวมใน scenario แทนการสร้างกฎ MOQ/loss/บวกราคา PK ซ้ำ การตรวจหัวคอลัมน์พบโครงสร้าง pricing history เดิม แต่ยังต้องตรวจสูตร หน่วย และสถานะก่อนใช้จริง.

ความล่าช้าหรือการขาดผล PK ต้องไม่หยุดการทำสูตรและ RM จึงแยกความพร้อมแต่ละหมวดและรองรับผลบางส่วนตามสิทธิ์ โดยยังไม่อนุญาต final quotation เมื่อข้อมูลบังคับไม่ครบ ข้อแลกเปลี่ยนคือยอมมีขั้นตรวจความเข้ากันของเวอร์ชันก่อนรวมผล เพื่อรักษาเจ้าของกฎชุดเดียวและให้แต่ละฝ่ายทำงานต่อได้.
