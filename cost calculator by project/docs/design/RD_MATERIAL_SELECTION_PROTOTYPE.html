เทียบข้อเสนอ 0/3

เลือก “เทียบ” ที่ข้อเสนอเพื่ออ่านความต่างพร้อมกัน ราคาและ MOQ เป็นคู่เดียวกันเสมอ

ข้อมูลที่ต้องทำต่อ · มุมมองต้นทางที่เสนอ

ใช้รายการเดิม แยกงานที่ต้องแก้ตามผู้รับผิดชอบ ก่อนเปลี่ยนหน้า RD Data Center จริงต้องตรวจหน้าที่ RD ใช้อยู่ก่อน

รายการสิ่งที่ขาดผู้รับผิดชอบสิ่งที่ผู้ใช้ควรทำได้
ข้อเสนอตัวอย่าง Eวันหมดอายุราคาจัดซื้อเปิดหลักฐาน → เติมวัน → ยืนยันเงื่อนไข
ข้อเสนอตัวอย่าง Fรับรอง specRDอ่าน spec และหลักฐาน → รับรองโดย RD
แถวตัวอย่าง 12ผู้ขายไม่ระบุจัดซื้อกลับแถวต้นทางเพื่อแก้ ไม่เดาผู้ขาย

สิ่งที่แยกออกจากหน้าค้นของ RD

รายละเอียด mapping, warnings จากตัวอ่าน, source row และประวัตินำเข้า ให้เปิดดูเมื่อจำเป็น ส่วนชื่อ / spec / Tier / MOQ / LT / สถานะต้องเห็นในหน้าค้นได้ทันที

ไม่เพิ่มทะเบียนราคา ไม่ใช้ Max Tier เป็นราคาของงาน ไม่แก้สิทธิ์ ไม่ sync ข้ามเครื่องในต้นแบบนี้
