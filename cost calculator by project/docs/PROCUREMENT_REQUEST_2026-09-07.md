# คำขอถึงจัดซื้อ — ข้อมูลที่ต้องเติมในชีตราคา RM (2026-09-07)

ผู้ส่ง: เจ้าของระบบ Formula Studio · ชีต: ตารางราคา RM ต้นฉบับ (แท็บ PriceOfRM หัวตารางแถว 3)
เอกสารนี้อ้างเฉพาะ**เลขแถว**ของชีต ไม่มีชื่อสาร ผู้ขาย หรือราคา — เปิดชีตดูประกอบ

## ทำไมต้องขอ

ระบบคำนวณต้นทุนอ่านชีตนี้**โดยตรง**แล้ว (ไม่ผ่าน RD Data Center อีก) อ่านได้ 143 ข้อเสนอจาก 90 วัสดุ
แต่ **ยังไม่มีรายการใดคิดต้นทุนได้** เพราะขาดสามอย่างที่ชีตไม่เคยมี — ระบบไม่เดาแทน
จัดซื้อ**กรอกแบบเดิมได้ทุกอย่าง** สิ่งที่ขอคือเพิ่มคอลัมน์ต่อท้าย ไม่ต้องย้ายหรือแก้คอลัมน์เดิม

## 1. เพิ่ม 5 คอลัมน์ต่อท้ายตาราง (ว่างได้ ระบบอ่านเท่าที่มี)

| หัวคอลัมน์ (พิมพ์ให้ตรง) | กรอกอะไร | รูปแบบที่อ่านได้ | จำเป็นแค่ไหน |
|---|---|---|---|
| `ขนาดสั่งเพิ่ม` | สั่งเพิ่มได้ทีละเท่าไร (ขนาดบรรจุ) | `25 kg` · `500 g` — เป็นน้ำหนัก ไม่ใช่ลัง/ถุง | **บังคับ** ก่อนคิดต้นทุน |
| `วันหมดอายุราคา` | ราคานี้ใช้ได้ถึงวันไหน | `2027-01-31` (ปี-เดือน-วัน) | **บังคับ** ก่อนคิดต้นทุน |
| `การรับรอง spec` | RD รับรอง spec ของสารตัวนี้แล้วหรือยัง | `ใช่` / เว้นว่าง = ยังไม่ตรวจ / คำอื่น = ไม่ผ่าน | **บังคับ** ก่อนคิดต้นทุน |
| `Lead Time` | จำนวนวันส่งของ | `14` หรือ `14 วัน` | ควรมี |
| `ชื่อเรียก` | ชื่อย่อ/ชื่อไทยที่ RD เรียกจริง | คั่นด้วย `;` เช่น `UC-II; คอลลาเจนไก่` | ไม่บังคับ — ช่วยให้ RD ค้นเจอเร็วขึ้น |

ค่าที่กรอกแล้วอ่านไม่ได้ ระบบจะ**ข้ามแถวนั้นพร้อมบอกเหตุผล** ไม่ใช้ค่าเดา

## 4. เมื่อกรอกแล้ว

ส่งไฟล์ (Excel/CSV ที่ export จากชีต) ให้ RD หรือ Admin กด "นำเข้าแคตตาล็อก RM" ในเมนู Cost Calculation — ระบบจะบอกทันทีว่ารับได้กี่รายการ ข้ามแถวไหนเพราะอะไร
รายการที่กรอกครบสามคอลัมน์บังคับจะเหลือขั้นเดียวคือจัดซื้อยืนยันเงื่อนไขซื้อ (สถานะ `confirmed`) ซึ่งตอนนี้ทำโดยระบุคอลัมน์ `status` = `confirmed` ในไฟล์ (หน้าจอกดยืนยันเป็นงานถัดไป)
