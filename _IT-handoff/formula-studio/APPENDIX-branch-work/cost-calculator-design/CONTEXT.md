# Cost Calculator by Project

คำศัพท์งานคำนวณต้นทุนและเสนอราคาผลิตภัณฑ์ OEM ตามข้อยืนยันใน SPEC.md และ REGISTRY.md

## Language

**Material Specification — ข้อกำหนดวัสดุ**:
รายละเอียดคุณลักษณะที่ใช้แยกและประเมินวัสดุสำหรับสูตร แม้ชื่อวัสดุจะเหมือนหรือคล้ายกันก็อาจเป็นคนละ spec
_Avoid_: ชื่อคล้ายกันจึงใช้แทนกันได้

**STD — ค่ามาตรฐานการผลิตและต้นทุน**:
ค่าฐานที่กำหนดไว้เพื่อใช้ในการคำนวณการผลิตและต้นทุน แยกจากค่าที่เกิดขึ้นจริงของงาน
_Avoid_: Actual cost

**Project — โครงการ**:
งานตามโจทย์ลูกค้าที่อ้างอิงตัวตนและ brief จาก Project Formula
_Avoid_: ทะเบียนลูกค้าหรือโครงการชุดใหม่ในเครื่องคำนวณต้นทุน

**Selected Tier — เงื่อนไขราคาที่เลือก**:
เงื่อนไขราคาหนึ่งชุดของวัสดุแต่ละรายการในแต่ละ scenario ซึ่งราคาและ MOQ ต้องมาจากชุดเดียวกันและได้รับการยืนยันจาก Procurement ก่อนใช้เสนอราคา
_Avoid_: เลือกราคาและ MOQ แยกกัน

**Consumption Cost — ต้นทุนวัสดุที่ใช้**:
ต้นทุนของวัสดุที่จัดสรรให้การผลิตตามปริมาณใช้และฐานการสูญเสียที่กำหนด
_Avoid_: เงินซื้อเต็ม MOQ

**Procurement Cash — เงินที่ต้องใช้ซื้อวัสดุ**:
มูลค่าซื้อวัสดุตามจำนวนที่ต้องซื้อจริง ภายใต้ MOQ และจำนวนเพิ่มต่อการสั่งซื้อที่เกี่ยวข้อง
_Avoid_: ต้นทุนใช้จริง

**Leftover Exposure — ภาระความเสี่ยงวัสดุเหลือ**:
ภาระจากวัสดุที่ซื้อมาแล้วเหลือจากงาน ซึ่งยังไม่อาจถือว่าจะใช้กับงานอื่นได้แน่นอน
_Avoid_: กำไรจากสต็อกเหลือ, ต้นทุนที่เรียกเก็บซ้ำโดยอัตโนมัติ

**Routing — ลำดับขั้นการผลิต**:
ชุดขั้นตอนการผลิตที่ RD กำหนดสำหรับงาน และเป็นฐานระบุต้นทุนการดำเนินงานให้ครบ

**Operation Cost — ต้นทุนการดำเนินงานผลิต**:
ต้นทุนตาม routing ซึ่งแยกค่าแรงทางตรง (DL) และค่าใช้จ่ายการผลิต (OH) โดยไม่คิดรายการเดียวกันซ้ำ

**Approved Quotation — ใบเสนอราคาที่อนุมัติแล้ว**:
ใบเสนอราคาเวอร์ชันที่ CEO อนุมัติและล็อกไว้ การเปลี่ยนแปลงต้องออก revision และผ่านการอนุมัติตามกติกาที่เกี่ยวข้อง
_Avoid_: ราคาปัจจุบันที่เปลี่ยนตามแหล่งข้อมูล, การอนุมัติทางเทคนิคเพื่อปล่อยระบบ


**Sourcing Request — คำขอจัดหาวัสดุ**:
คำขอให้ Procurement เสนอวัสดุหรือ spec ที่ต้องการเมื่อไม่มีรายการให้เลือกใน Data Center โดยอ้างอิงความต้องการของโครงการ
_Avoid_: วัสดุที่พร้อมใช้คำนวณ

**Internal Cost Estimate — ต้นทุนประมาณการภายใน**:
ผลประมาณต้นทุนจากฐานข้อมูลของงานก่อนกฎบวกราคา สำหรับผู้มีสิทธิ์เห็นต้นทุน; ผลที่ Sales/OPC เห็นใช้ยอดหลังบวกตามขอบเขตสิทธิ์
_Avoid_: ราคาขายที่อนุมัติแล้ว

**General Commercial Terms — เงื่อนไขการซื้อกลาง**:
เงื่อนไขที่นำกลับใช้ข้ามโครงการได้ขณะยังมีผล เมื่อวัสดุ vendor Tier และข้อจำกัดตรงกัน
_Avoid_: ราคาพิเศษเฉพาะโครงการ


**Disclosable Material Name — ชื่อแสดงวัสดุที่เปิดเผยได้**:
ชื่อที่ RD กำหนดให้ Sales/OPC เห็นแทนชื่อวัตถุดิบเต็มหรือชื่อบนใบเสนอราคาของซัพพลายเออร์
_Avoid_: ชื่อซัพพลายเออร์, ชื่อเต็มของวัตถุดิบ

**Partial Cost Estimate — ต้นทุนประมาณการเฉพาะส่วนที่ทราบ**:
ต้นทุนที่คำนวณได้จากส่วนที่มีข้อมูล พร้อมระบุส่วนที่ยังขาด จึงยังไม่ใช่ต้นทุนรวมต่อชิ้นสำหรับเสนอราคา
_Avoid_: ต้นทุนรวม, ราคาพร้อมเสนอ


**Selling Unit — หน่วยขาย**:
หน่วยที่กำหนดจำนวนส่งมอบให้ลูกค้า โดยมีขนาดบรรจุชัดเจน เป็นฐานแสดงต้นทุนต่อหน่วยขาย
_Avoid_: ชิ้นที่ไม่ระบุว่าเป็นซอง กล่อง หรือหน่วยใด

**Planned Loss — การสูญเสียที่วางแผนไว้**:
การสูญเสียที่ RD และฝ่ายผลิตกำหนดตามขั้นผลิตและวัสดุ โดยแยกเนื้อผลิตภัณฑ์กับบรรจุภัณฑ์
_Avoid_: ค่าเผื่อซ้ำทุกชั้น, ค่าว่างเท่ากับศูนย์


**Adjusted Category Amount — ยอดหลังบวกของหมวด**:
ยอดของ RM, PK หรือ Operation หลังใช้กฎราคาของหมวดที่กำหนดแล้ว เป็นฐานยอดที่อนุญาตให้ Sales/OPC และฝ่ายอื่นที่ไม่มีสิทธิ์เห็นราคาจริงรับทราบ
_Avoid_: ต้นทุนจริงก่อนบวก, ราคาขายสุดท้ายที่อนุมัติแล้ว

**Base Cost — ต้นทุนก่อนบวก**:
ต้นทุนที่คำนวณจากปริมาณและฐานราคาของงานก่อนใช้กฎบวกราคา ซึ่งผู้ใช้เรียกว่าต้นทุนจริงในบริบทสิทธิ์ราคา
_Avoid_: Actual production cost ที่เกิดขึ้นหลังผลิต
