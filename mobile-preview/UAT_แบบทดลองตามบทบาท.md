# แบบทดลอง Formula Studio มือถือ — ข้อมูลจำลอง

สถานะ: **รอเจ้าของงานและผู้แทนทดลอง** แบบนี้ยังไม่มีผลรับรอง และไม่ใช่การอนุมัติใช้งานระบบจริง

## ก่อนเริ่ม

1. ผู้ดูแลเปิดตัวอย่างด้วยคำสั่งใน [README.md](README.md) แล้วเปิด `http://127.0.0.1:8767/` บนเครื่องเดียวกับที่เปิดบริการ ที่อยู่นี้ไม่ได้เปิดให้เครื่องอื่นโดยอัตโนมัติ
2. ทุกคนใช้ชื่อและข้อมูลสมมติ ห้ามกรอกข้อมูลลูกค้า สูตร ต้นทุน หรือข้อมูลส่วนบุคคลจริง ข้อมูลหายเมื่อโหลดหน้าซ้ำหรือกด **เริ่มตัวอย่างใหม่**
3. เปิดเมนูซ้าย → **ทดลองมุมมองบทบาท** → เลือกบทบาทที่ต้องทดสอบ ไม่ใช่การลงชื่อเข้าใช้จริง
4. ถ้าจะเดินการอนุมัติครบ 4 ฝ่าย ให้ทดลองต่อเนื่องในแท็บเดียวกันโดยเปลี่ยนบทบาททีละฝ่าย อย่าโหลดหน้าใหม่ระหว่างทาง การสลับบทบาทไม่ได้ยืนยันตัวตนของผู้ทดสอบ
5. บันทึกผลแต่ละข้อเป็น **ผ่าน / ไม่ผ่าน / ยังไม่ได้ทดลอง** พร้อมสิ่งที่พบ; ถ้าพบข้อไม่ตรงระบบเดิม บันทึกหน้าจอและขั้นตอนโดยไม่มีข้อมูลจริง

**หลักฐานก่อนเริ่ม:** ต้องระบุผู้แทนของแต่ละฝ่ายและรุ่นระบบเดิมที่ System Owner ยืนยัน หากยังไม่มี ให้ทดลองความสะดวกของหน้าจอได้ แต่บันทึกการเทียบ workflow และการตรวจรับเป็น **ยังไม่ได้ทดลอง** ผลทดสอบอัตโนมัติไม่ใช่ลายรับรองของผู้แทน

## เส้นทางทดลองรายบทบาท

| ผู้แทน | สิ่งที่ให้ทดลอง | ผลที่ควรเห็นในตัวอย่าง | ผล / ข้อสังเกต |
|---|---|---|---|
| Sales | ค้นหางาน A00001; สร้างบรีฟสมมติพร้อมสาร 2 รายการ; ส่งข้อความ; อนุมัติ Sales | เห็นงานตัวอย่างของ Sales และงานที่สร้างเอง; สารแสดงในรายละเอียด; ข้อความและสถานะเปลี่ยนในแท็บ | รอทดลอง |
| PD | เปิดงาน A00001; ดูและแก้ปริมาณสาร; บันทึก; อนุมัติ PD | เห็นค่าที่คำนวณจากปริมาณ × ความเข้มข้น; การแก้สูตรล้างสถานะอนุมัติเดิม; เลือกอนุมัติ PD ได้ | รอทดลอง |
| RA | เปิดงาน A00001; เปิดแชต; ส่งข้อความ; อนุมัติ RA | เห็นรายละเอียดและข้อความตัวอย่าง; อนุมัติ RA ได้; ไม่มีปุ่มแก้สูตร | รอทดลอง |
| RD | เปิดงาน A00001; ตรวจสูตรและแชต; อนุมัติ RD | เห็นสูตรตัวอย่างและอนุมัติ RD ได้; ไม่มีปุ่มแก้สูตร | รอทดลอง |
| OPC | เปิดงาน; สร้าง/แก้บรีฟ; ปิดและเปิดงานอีกครั้ง; ดูทางเลือกส่งออก | สถานะงานเปลี่ยนในตัวอย่าง; ส่งออก CSV และ Excel ตัวอย่างงานเดียวได้; หลังอนุมัติจำลองครบ ให้ทดลองส่งออก Excel จากแชต | รอทดลอง |
| MKT | สร้างและแก้บรีฟสมมติ; เปิดห้องแชตและส่งข้อความ | งานและข้อความอยู่เฉพาะในแท็บ; ไม่มีปุ่มปิดงานหรืออนุมัติ | รอทดลอง |
| Purchasing | เปิดงานและส่งข้อความในแชต | ดูงานและส่งข้อความตัวอย่างได้; ไม่มีปุ่มสร้างบรีฟ แก้สูตร ปิดงาน หรืออนุมัติ | รอทดลอง |
| Admin | ดูงาน ประวัติตัวอย่าง และบทบาทในเมนู; ทดลองอนุมัติและปิด/เปิดงาน | เห็นปุ่มตามบทบาท Admin จำลอง; รายการประวัติไม่ใช่ audit จริง และไม่เปลี่ยนบัญชีจริง | รอทดลอง |

## ทดลองร่วมกันและจุดผิดพลาด

- ให้ Sales, PD, RA และ RD อนุมัติ A00001 ทีละฝ่ายในแท็บเดียวกัน ตรวจว่าแสดงครบ 4/4; เมื่อ PD แก้สูตร ให้ตรวจว่าสถานะกลับไปรอตรวจใหม่
- เริ่มแก้บรีฟหรือพิมพ์ข้อความแล้วกดออกจากหน้า ตรวจว่ามีคำเตือนก่อนทิ้งข้อความ; เลือกอยู่ต่อแล้วตรวจว่าสิ่งที่กรอกยังอยู่
- สร้างงานโดยไม่ใส่ลูกค้าและแบรนด์ ตรวจข้อความแจ้งและแก้ไขได้โดยข้อมูลอื่นไม่หาย
- ตรวจหัวข้อที่ย่อ–ขยาย เมนูซ้าย ขนาดปุ่ม การเลื่อน และการใช้มือเดียวบนอุปกรณ์ของผู้ทดลอง บันทึกตำแหน่งที่ใช้งานยาก
- ทดลองนำเข้า Excel หลายงานด้วยข้อมูลสมมติ ตรวจรหัสและจำนวนสารในรายการก่อนกดสร้าง และตรวจว่าสารอยู่ในงานที่ถูกต้อง
- เปิดงานเดิมเพื่อแก้ เลือกไฟล์งานเดียวที่มีเพียงชื่อลูกค้า แล้วตรวจคำเตือน: ช่องที่ไม่มีในไฟล์คงเดิม แต่รายการสารถูกแทนทั้งหมด แม้ไฟล์ไม่มีสาร กดยกเลิกก่อนและตรวจว่าข้อมูลไม่เปลี่ยน หากทดลองยืนยันต่อให้ใช้ข้อมูลสมมติเท่านั้น
- ในฟอร์ม เลือก **ทดลองผลการบันทึก** เป็นรอคิวหรือไม่ทราบผล แล้วบันทึก ตรวจว่าข้อมูลที่กรอกยังอยู่และข้อความไม่อ้างว่าบันทึกจริง ผลเป็นการจำลอง ไม่มีคิวหรือบริการจริง
- หลังแก้ข้อมูล ลองรีโหลดแล้วเลือกอยู่ต่อหากเบราว์เซอร์แสดงคำเตือน ตรวจว่าข้อมูลยังอยู่ การเตือนอาจไม่ปรากฏเมื่อระบบมือถือปิดแอป และไม่ใช่การเก็บข้อมูลถาวร
- ตรวจข้อมูลเทียบกับระบบเดิมที่เจ้าของงานระบุรุ่นแล้ว โดยเฉพาะช่องฟอร์ม สิทธิ์ การอนุมัติ และไฟล์นำเข้า/ส่งออก

## ประเด็นที่ต้องแยกไว้ก่อนรับรอง

| ประเด็น | สถานะปัจจุบัน | การตัดสินใจ / ผลทดลอง |
|---|---|---|
| บทบาท | ตัวอย่างมี 8 บทบาท แต่สำเนาระบบเดิมที่ตรวจมี Oversea เพิ่ม และสิทธิ์ MKT ไม่ตรงกัน | รอเจ้าของระบบยืนยันรุ่นและสิทธิ์; ยังไม่รับรองว่าครบทุกบทบาท |
| ถอนอนุมัติ | ตัวอย่างไม่ล้างทุกฝ่ายหรือเปิดงานกลับเหมือนสำเนาระบบเดิมที่ตรวจ | รอเจ้าของงานยืนยันกติกา; ยังไม่รับรองขั้นตอนนี้ |
| คำนวณสาร | ความเข้มข้น 0% หรือว่างให้ผลต่างจากสำเนาระบบเดิมที่ตรวจ | รอ RD/RA และเจ้าของงานยืนยัน; ไม่ใช้ผลตัวอย่างตัดสินสูตรหรือ อย. |
| คอนเซปและสารเดิม | ข้อมูลคอนเซป จุดขาย และรูปแบบสารยังไม่เข้ากันครบ; ตัวเชื่อมทดลองหยุดการเปลี่ยนคอนเซปบางงานเป็นการชั่วคราว | รอแหล่งข้อมูลและวิธีคำนวณที่ยืนยันแล้ว; ยังไม่รับรองการเชื่อม |
| บันทึกล่าช้า | การอ่านรายการงานอย่างเดียวแยกคำขอที่รอจริงกับคำขอที่คิวหยุดเพราะขัดแย้งไม่ได้ | ต้องทดสอบวิธีติดตามผลที่มีสิทธิ์ก่อนเชื่อม; ตัวอย่างไม่มีคิวจริง |

ถ้าผู้ทดลองพบว่าเกิดปัญหาที่ระบุไว้ ให้บันทึกผลตามจริง ไม่ถือว่าผ่านเพียงเพราะปัญหาอยู่ในรายการนี้

## สิ่งที่ยังทดลองแทนของจริงไม่ได้

Excel อนุมัติจริงจากแชต, PDF ในรูปแบบเดิม, การตรวจ อย., การจัดการบัญชีจริง, ประวัติจริง และการทำงานข้ามเครื่องยังไม่รองรับในตัวอย่าง หน้าพิมพ์สามารถเลือกบันทึกเป็น PDF หากอุปกรณ์รองรับ แต่ยังต้องทดสอบบนอุปกรณ์จริง; CSV เป็นการทดลองแยกและไม่ใช่ไฟล์อนุมัติ Excel ของระบบเดิม ห้ามนำสถานะหรือผลคำนวณจากตัวอย่างไปใช้ตัดสินใจด้านคุณภาพหรือกฎระเบียบ
