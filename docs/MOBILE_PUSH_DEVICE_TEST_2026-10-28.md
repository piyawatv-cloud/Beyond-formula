# ผลทดสอบแจ้งเตือนบน Android — Formula Studio

วันที่ 28 ต.ค. 2026 เวลาไทยประมาณ 18:48 · สภาพแวดล้อมทดสอบเฉพาะกิจ · สถานะ: ผ่านเฉพาะกรณีปิดแท็บ Chrome

## ขอบเขต

A001T, Android 16, Chrome; หน้าทดสอบชั่วคราวบน localhost ที่เชื่อมผ่าน USB ใช้ Web Push ของเบราว์เซอร์กับข้อความสังเคราะห์ ไม่มีบัญชี Formula Studio ไม่มีการเชื่อมฐานข้อมูลจริง ข้อมูลสมัครและกุญแจทดสอบเก็บเฉพาะหน่วยความจำของบริการทดสอบ ไม่บันทึกใน repository หรือรายงานนี้

## ขั้นตอนและผล

1. ผู้ใช้อนุญาตการรับแจ้งเตือนและปิดแท็บทดสอบใน Chrome แล้วแจ้งว่าปิดแท็บแล้ว
2. บริการทดลองส่งคำขอหนึ่งครั้ง ผลตอบรับ `200 accepted` หมายถึงบริการรับคำขอ ไม่ใช่หลักฐานว่าผู้ใช้เห็น
3. ตรวจแบบเจาะจงชื่อแจ้งเตือนทดสอบในสถานะระบบแจ้งเตือนของอุปกรณ์: พบรายการทดสอบ โดยไม่รายงานแจ้งเตือนอื่น
4. ผู้ใช้ยืนยันว่าเห็นแจ้งเตือน “Formula Studio — ทดสอบ” หลังปิดแท็บ

## ขอบเขตของข้อสรุป

นี่คือการทดสอบปิดแท็บ ไม่ใช่การบังคับปิด Chrome หรือทดสอบแอป APK หลังถูกปิด ทดสอบเพียงหนึ่งอุปกรณ์และหนึ่งข้อความ ยังไม่ได้ตรวจ iOS, สลับบัญชี, ถอนสิทธิ์, อุปกรณ์ offline, ประสิทธิภาพ, push ซ้ำ, privacy บน lock screen, สิทธิ์จริง, ระบบคิว, UAT หรือการเชื่อม Formula Studio. ห้ามถือว่าระบบพร้อม production

หลังทดสอบลบการเชื่อมต่อพอร์ต USB ชั่วคราว หยุดบริการทดสอบ และลบกุญแจควบคุมชั่วคราวแล้ว; การสมัครและ worker ที่ Chrome อาจเก็บบนโทรศัพท์ยังไม่ได้ยืนยันว่าลบแล้ว
