วันที่ 28 ต.ค. 2026 เวลาประมาณ 18:55 น. เวลาไทย · สถานะ: ผ่านเฉพาะขอบเขตทดสอบที่ระบุ ไม่ใช่การรับรอง production

## ขอบเขต

ใช้แบบจำลองงานจาก `mobile-preview/index.html` เชื่อมผ่าน `mobile-preview/simulation/scenario-lab.cjs` และ `push-lab.cjs` ไปยัง Web Push ของ Chrome บน A001T Android 16 โดยกำหนด Sales และ PD เป็นตัวตนจำลอง ไม่เชื่อมฐานข้อมูลจริง ข้อมูลสมัครและกุญแจทดสอบอยู่ในหน่วยความจำ/ไฟล์ชั่วคราว ไม่บันทึกลงรายงานหรือ repository

## หลักฐานและผล

- `node mobile-preview/simulation/scenario.test.cjs`: PASS; ตรวจสิทธิ์ในข้อมูลจำลอง รวม Sales ที่ไม่มีสิทธิ์ดูงานผู้อื่น ผู้ส่งไม่รับแจ้งเตือนตนเอง ผู้รับที่ถูกถอน และเหตุการณ์ซ้ำไม่เพิ่มข้อความเดิม; ตรวจกรณีชน ID ต่างเนื้อหาและส่งไม่สำเร็จ
- `node mobile-preview/simulation/push.test.cjs`: PASS; ทดสอบการจำลองส่งซ้ำ/พร้อมกัน/สิทธิ์/ไม่เผยข้อความภายใน payload และส่งใหม่หลังขัดข้อง; `node mobile-preview/test.cjs`: PASS
- ทดลองอุปกรณ์รอบแรก: คำขอที่ไม่มีสิทธิ์ถูกปฏิเสธ (`403`); เหตุการณ์งานและแชตได้รับผลตอบรับจากบริการอย่างละ 1 ครั้ง และเมื่อส่งซ้ำจำนวนส่งเพิ่ม 0 แต่ผู้ใช้และระบบโทรศัพท์ไม่พบแจ้งเตือน ผลรอบนี้ **FAIL** โดยยังไม่ทราบสาเหตุ
- ทดลองรอบสองในหน้า/พอร์ตทดสอบใหม่หลังลงทะเบียนใหม่และผู้ใช้ยืนยันปิดแท็บ: คำขอที่ไม่มีสิทธิ์ `403`; งานและแชตอย่างละ 1 ส่ง, ซ้ำอย่างละ 0 ส่ง; ตรวจพบข้อความแจ้งเตือนทั้งสองชนิดในระบบโทรศัพท์ และผู้ใช้ยืนยันเห็นทั้งสองอย่างละหนึ่ง
- การตอบรับจากบริการเป็นหลักฐานว่ารับคำขอเท่านั้น หลักฐานการมองเห็นคือการตรวจรายการบนเครื่องและคำยืนยันผู้ใช้

## ข้อจำกัดและความเสี่ยงที่เหลือ

- ปิดแท็บ Chrome ไม่เท่ากับบังคับปิด Chrome หรือปิดแอป APK; ยังไม่ทดสอบกรณีดังกล่าว, iOS, อุปกรณ์ offline, ระบบคิวถาวร, สิทธิ์ที่ถอนระหว่างส่ง, หลาย process, restart, และการรับประกันส่งถึง/เรียงลำดับ
- บทบาทในตัวจำลองไม่ใช่บัญชีจริง ไม่ใช่การพิสูจน์ authorization ของฐานข้อมูล และไม่ใช่กติกาการส่งจริงที่เจ้าของงานอนุมัติ; การกันส่งซ้ำและเหตุการณ์เก็บในหน่วยความจำเท่านั้น
- สาเหตุรอบแรกที่ไม่แสดงยังไม่ยืนยัน; การเปลี่ยนพอร์ตและลงทะเบียนใหม่ไม่พิสูจน์ root cause ต้องตรวจซ้ำก่อนใช้งานจริง
- หลังทดสอบหยุดบริการชั่วคราว ลบการเชื่อมต่อ USB ชั่วคราวและกุญแจควบคุมในเครื่องแล้ว; การสมัคร/worker บน Chrome ยังไม่ได้ยืนยันว่าลบแล้ว
- ไม่มี production access/schema/permission/deployment, UAT, independent review หรือ PR
