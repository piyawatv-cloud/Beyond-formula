## การทดสอบผู้ใช้จริง — A04698

System Owner แจ้งว่ามีเครื่องภายนอกและ Sales/PD พร้อม และแจ้งรหัส A04698 เป็นใบงานทดสอบ หลังผู้ใช้แจ้งว่าส่งข้อมูลและกด PD Pass แล้ว ตรวจแบบอ่านอย่างเดียวพบในฐานกลางใบงาน 1 ใบ ห้องแชต 1 ห้อง ข้อความ 2 รายการ และ PD Pass 1 รายการ หน้า Dashboard ของบัญชีเจ้าของบน iMac แสดงรหัส A04698 ชื่องานทดสอบและสถานะแชต 1/4 การตรวจนี้ยังไม่พิสูจน์ว่าเนื้อหาข้อความทั้งสองตรงตามที่ผู้ส่งตั้งใจ หรือยืนยันเครือข่ายและเวลาจากเครื่องภายนอก; จำนวนส่วนผสมในฐานเป็น 0 จึงยังต้องรอผู้ทดสอบยืนยันว่าได้แก้สูตรหรือไม่ และมีข้อความเตือนหรือรอยืนยันค้างหรือไม่ การกดส่ง/อนุมัติทำโดยผู้ทดสอบ ไม่ใช่ agent

ผู้ใช้แจ้งภายหลังว่าไม่มีค้างและแก้สูตรแล้ว ตรวจฐานกลางพบส่วนผสม 2 รายการ ข้อความ 4 รายการ และ PD Pass 0 รายการ; ประวัติระบุการถอน PD Pass ก่อนบันทึกแก้สูตรในห้องแชต หน้า Dashboard อีกเครื่องระหว่างแรกยังแสดง 0 รายการ/1 ต่อ 4 แล้วอัปเดตเองเป็น 2 รายการ/0 ต่อ 4 โดยไม่กดอัปเดต ไม่ได้จับเวลาเริ่มและสิ้นสุดอย่างแม่นยำ และยังไม่ได้เทียบเนื้อหากับที่ผู้ทดสอบตั้งใจ; จึงไม่ใช่ผลวัด 0.5 วินาที และไม่สรุปว่า withdrawal เป็นผลจากการแก้สูตร

ผู้ใช้ยืนยันเพิ่มเติมว่าตั้งใจให้สูตรมี 2 รายการและเปิดดูอีกครั้งยังแสดง 2 รายการตรงกัน ข้อความนี้ยืนยันจำนวนและการเปิดดูซ้ำ ยังไม่ใช่หลักฐานเปรียบเทียบชื่อหรือค่าทุกช่องจากต้นฉบับ และยังไม่ครอบคลุมการเชื่อมต่อสะดุดจริง
